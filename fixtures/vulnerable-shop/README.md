# vulnerable-shop (synthetic demonstration project)

**This project is deliberately defective and exists only to exercise CodeLens
AI.** It is not a real product, the credentials in it are fake, and it must
never be deployed or used as a starting point.

Every seeded defect is annotated in place with a `DEFECT (...)` comment and
enumerated in `GROUND_TRUTH.json`, which the precision/recall harness scores
scanner output against.
